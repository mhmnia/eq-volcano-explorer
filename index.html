Data note: the proximity results describe spatial context only. A volcano inside the selected radius does not by itself establish earthquake-triggered volcanic activity.
Status note: colours are derived from the Last Known Eruption field of the active Smithsonian GVP catalogue, not from real-time monitoring. The GVP Holocene list is a static compilation, so it cannot report which volcanoes are erupting today; for that, consult the GVP Weekly Activity Report. Volcanoes whose GVP Activity Evidence is Unrest / Holocene or Evidence Uncertain have no dated eruption and are therefore listed with an unknown last eruption year.

Related online resources

Three independent portals that complement this explorer: a multi-agency seismic feed, a plate-boundary volcano map, and an InSAR deformation database. Open each in a new tab.

Real-time seismicity

VolcanoDiscovery — Earthquake monitor

earthquakes.volcanodiscovery.com

A near-real-time earthquake feed aggregated from dozens of national and international agencies, so a moderate event often has a better regional solution here than in a single global catalogue. The same map carries VolcanoDiscovery’s volcano status colours and a dedicated “quakes near active volcanoes” view.

Plate-boundary context

Tectonic Plates Map — Volcano layer

tectonicplatemap.com/volcanoes

An interactive world map of Holocene volcanoes drawn on top of tectonic plate boundaries, filterable to the last year, the last 100 years, or the complete Holocene list. Useful for judging where a rupture sits along an arc and which segment is worth screening first.

Ground deformation

COMET Volcanic & Magmatic Deformation Portal

comet.nerc.ac.uk/comet-volcano-portal

A worldwide database of volcanic ground deformation built on automatically processed LiCSAR Sentinel-1 interferograms, with online time-series, profile and machine-learning deformation-probability tools. It also archives published null results, so a volcano’s deformation history can be checked before and after an earthquake.
